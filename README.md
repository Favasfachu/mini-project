# Restaurant Sales Analysis – Power BI Dashboard

## Overview
This project involves analyzing restaurant sales data and creating an interactive dashboard using Power BI.  
The dashboard provides insights into sales performance, customer behavior, and product trends to support data-driven decision-making.

---

## Objectives
- Analyze restaurant sales data to identify trends and patterns
- Build an interactive and visually clear Power BI dashboard
- Track key performance indicators (KPIs)
- Present insights in a business-friendly format

---

## Dataset
The dataset includes restaurant sales information such as:
- Order ID
- Order Date
- Item Name / Category
- Quantity Sold
- Sales Amount
- Payment Mode
- Customer Type

*(Dataset used for learning and analytical purposes)*

---

## Dashboard Features
- Total Sales
- Total Orders
- Average Order Value (AOV)
- Sales by Item / Category
- Sales Trends over Time
- Payment Mode Analysis
- Top Performing Items

---

## Tools Used
- Power BI
- Microsoft Excel (for initial data cleaning)
- DAX (for calculated measures)
